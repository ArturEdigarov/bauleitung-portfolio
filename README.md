# Портфолио Oleksii Yediharov

## Запуск

```bash
npm install
npm run dev
```

Откроется адрес вида `http://localhost:5173`.

Для сборки готового сайта (например, для загрузки на хостинг):

```bash
npm run build
```

Готовый сайт появится в папке `dist/`.

## Как добавить свои фото и тексты

1. **Тексты о человеке** — файл `src/data/profile.js`. Опыт, образование, навыки, языки, контакты.
2. **Кейсы (карточки проектов)** — файл `src/data/cases.js`. Для каждого кейса: заголовок, локация, год, описание, характеристики.
3. **Фотографии** — кладите в папку `public/cases/`, например:
   - `public/cases/projekt-1/cover.jpg` — обложка карточки
   - `public/cases/projekt-1/1.jpg`, `2.jpg`, `3.jpg` — фото внутри страницы кейса
   - `public/cases/hero.jpg` — фото/портрет на главном экране

   Пути в `cases.js` уже на них ссылаются — просто положите файлы с такими именами.
   Пока фото нет, вместо него показывается аккуратная заглушка "Foto folgt", сайт не ломается.

4. Хотите добавить пятый, шестой кейс — скопируйте один объект в `cases.js`, поменяйте `id` (должен быть уникальным) и данные.

## Структура

```
src/
  data/profile.js       — все тексты о человеке
  data/cases.js         — все кейсы/проекты
  components/           — переиспользуемые блоки (шапка, карточка, футер...)
  pages/Home.jsx         — главная страница
  pages/CaseDetail.jsx   — страница одного кейса (открывается по клику на карточку)
public/cases/            — сюда кладутся фотографии
```
